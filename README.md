# 🎲 '운이 좋으면 이길까?' 홀짝 주사위

청소년 도박중독 예방 강의에서 쓰는 **주사위 홀짝게임 교육보조재**입니다.
불법 온라인 도박사이트 같은 화면에서 확률게임을 직접 해 보면서, 학생들이 **"도박은 구조적으로 질 수밖에 없다"**는 것을 체험하도록 만드는 것이 목표입니다.

> ⚠️ 이 프로그램은 교육용입니다. 실제 돈이나 베팅 기능은 없습니다. 자금은 각 조가 엑셀로 따로 관리합니다.

---

## 1. 사용 환경

- **화면 배치:** 모니터 왼쪽에 엑셀(조별 자금표), 오른쪽에 이 프로그램을 세로로 길게 띄웁니다.
- **화면 비율:** 모바일처럼 세로가 긴 비율(9:16 기준, 예: 430×860)
  - 스크롤 없이 **한 화면에 타이머와 주사위가 모두 보여야** 합니다.
  - 창 크기가 바뀌어도 비율을 유지하고 가운데에 맞춥니다.
- **실행 방식:** `index.html` 파일 하나를 브라우저(Chrome 권장)로 엽니다.
  - 인터넷이 없는 교실에서도 돌아가도록 외부 라이브러리, 이미지, 음원 파일을 쓰지 않습니다.
  - 소리는 Web Audio API로 직접 만듭니다.

---

## 2. 게임 방식 (모드 선택)

프로그램을 열면 **시작 화면에서 모드를 먼저 고른 뒤** 게임 화면으로 넘어갑니다. 게임 화면에는 모드 선택 버튼이 보이지 않습니다.

- 다른 모드로 바꾸려면 새로고침(`F5`)으로 시작 화면에 돌아갑니다.
- 모드를 다시 고르면 확률 계산이 처음부터 다시 시작됩니다.

### 2-1. 일반판

| 항목 | 내용 |
|---|---|
| 시작 자금 | 조별 1,000닷 (가상화폐) |
| 베팅 단위 | 100닷 |
| 베팅 방식 | 짝수에만 베팅 |
| 짝수가 나오면 | 베팅 금액의 **1.8배** 획득 |
| 홀수가 나오면 | 베팅 금액 **전액 손실** |
| 승리 조건 | 마지막 라운드까지 자금을 가장 많이 불린 조 |

### 2-2. UPGRADE판

| 항목 | 내용 |
|---|---|
| 시작 자금, 베팅 단위 | 일반판과 같음 |
| 베팅 방식 | 홀과 짝 중 한 곳에 베팅 |
| 맞히면 | 베팅 금액의 **1.5배** 획득 |
| 틀리면 | 베팅 금액 **전액 손실** |
| 승리 조건 | 마지막 라운드까지 자금을 가장 많이 불린 조 |

- **홀수:** 주사위 눈 1, 3, 5
- **짝수:** 주사위 눈 2, 4, 6

## 3. 확률 규칙 (가장 중요)

### 공통 규칙
1. 홀/짝을 **먼저 정하고**, 그 안에서 눈금(예: 짝수면 2·4·6 중 하나)을 똑같은 확률로 고릅니다.
2. 난수는 `Math.random()` 대신 `crypto.getRandomValues()`를 씁니다.
3. **같은 결과가 너무 길게 이어지지 않게** 합니다.

### 3-1. 일반판: 짝 40% / 홀 60% 고정

짝수가 계속 나오면 학생들이 "도박으로 돈을 벌 수 있다"고 착각합니다. 그래서 비율이 정확히 지켜지도록 **10라운드 묶음(덱)** 방식을 씁니다.

- 10번마다 **짝 4개, 홀 6개**를 섞어 차례대로 냅니다.
  - 짧은 수업에서도 비율이 운에 따라 흔들리지 않고 정확히 40:60이 됩니다.
- 섞은 뒤 아래 조건을 만족하지 않으면 다시 섞습니다. 앞 묶음의 마지막 결과와 이어지는 부분도 함께 검사합니다.
  - **짝 연속 최대 2회:** 연속으로 따는 경험을 막습니다.
  - **홀 연속 최대 3회:** 너무 뻔하게 지기만 하는 것도 막습니다.
- 10라운드를 넘겨도 다음 묶음이 이어서 같은 방식으로 나옵니다.

### 3-2. UPGRADE판: 예측할 수 없게

학생이 패턴을 읽으려 해도 읽을 수 없어야 합니다. 그래서 덱 방식을 쓰지 않습니다. 덱은 후반으로 갈수록 남은 결과를 추측할 수 있기 때문입니다.

- 기본은 매 라운드 **홀 50% / 짝 50%**로 따로 뽑습니다.
- 같은 결과가 이어지면 다음에 또 나올 확률을 낮춥니다.
  - 2회 연속: 다음에 같은 결과가 나올 확률 35%
  - 3회 연속: 다음에 같은 결과가 나올 확률 15%
  - 4회 연속: 다음은 반드시 반대 결과 (**최대 4연속**)
- 정해진 주기나 규칙적인 번갈아 나오기는 없어야 합니다.

### 참고: 기대값 (진실 공개 시간용)

| 모드 | 이길 확률 | 배당 | 100닷 베팅 시 기대값 |
|---|---|---|---|
| 일반판 | 40% | 1.8배 | 100 × 0.4 × 1.8 = **72닷 (−28%)** |
| UPGRADE판 | 50% | 1.5배 | 100 × 0.5 × 1.5 = **75닷 (−25%)** |

어느 쪽이든 **오래 할수록 반드시 잃는 구조**입니다. 수업 마무리에 이 표를 보여주면 좋습니다.

## 5. 기능 상세

### 5-1. 카운트다운 타이머 (화면 상단)

학생들이 **베팅할지 말지 조별로 토의하는 시간**을 주기 위한 타이머입니다.

- **시간 설정:** 강사가 직접 정합니다.
  - `−` / `+` 버튼은 5초 단위로 조정하고, 숫자를 직접 입력할 수도 있습니다.
  - 빠른 선택 버튼: 10초, 30초, 60초
  - 마지막 설정값은 다음에 열 때 기억합니다(localStorage).
- **표시 방식:** 숫자가 **한 칸씩 내려가는 모양**입니다. 숫자가 바뀔 때 위에서 아래로 넘어가는 플립/슬라이드 애니메이션을 넣습니다.
  - 남은 시간이 5초 이하가 되면 0.1초 단위(`4.9 → 0.0`)로 바뀌고, 글자가 빨간색으로 깜빡입니다.
- **소리:**
  - **5초 남았을 때부터** 틱톡틱톡 소리가 납니다. 0.5초 간격으로 높은음과 낮은음을 번갈아 냅니다.
  - **0.0초가 되면** 짧은 알람(삐-삐-, 약 1초)이 울리고, 화면에 "베팅 마감!"이 표시됩니다.
- **조작:** 시작 / 일시정지 / 리셋
- **음소거 버튼:** 화면 구석에 둡니다.
- **브라우저 소리 제한 대응:** 브라우저는 첫 클릭 전에는 소리를 막습니다. 그래서 처음 어떤 버튼을 누를 때 오디오를 활성화합니다.

### 5-2. 3D 주사위 (타이머 아래)

- CSS 3D transform으로 만든 **입체 정육면체 주사위**입니다. 6면에 눈이 점으로 그려집니다.
- **[주사위 굴리기]** 버튼을 누르거나 **스페이스바**를 누르면 굴립니다.
  1. 결과는 3장의 규칙으로 **먼저 정합니다**.
  2. 주사위가 여러 바퀴 구르고 튀는 모션을 약 2초간 보여줍니다.
  3. 정해진 눈이 위(정면)를 향하도록 멈춥니다.
- 굴러가는 동안에는 버튼을 막아 두 번 눌리지 않게 합니다.
- 멈출 때 짧은 효과음을 냅니다. 결과 글자나 기록은 따로 띄우지 않습니다.

### 5-3. 디자인 / 분위기

**불법 온라인 도박사이트 느낌**을 내되, 모든 문구는 **도박 반대 메시지**로 바꿉니다.

- **배경:** 검정·짙은 보라 배경에 네온 빛 효과를 줍니다. 금색과 빨간색 포인트, 반짝이는 조명 효과를 넣습니다.
- **글꼴:** 굵고 화려한 카지노풍 글꼴을 쓰되, 시스템 글꼴로 대체할 수 있어야 합니다.
- **배너와 슬로건:** 도박사이트의 "잭팟!", "첫 충전 보너스!" 자리에 아래 문구를 넣습니다.
  - 🚫 도박 안돼! 절대금지! 🚫
  - 💀 도박은 반드시 잃는 게임입니다
  - ⚠️ 한 번의 클릭이 중독의 시작
  - 📞 도박 문제 상담: 1336 (한국도박문제예방치유원)
- 상단은 흐르는 마퀴 배너, 하단은 깜빡이는 네온 배너로 만듭니다.
- 진짜 도박사이트로 착각하지 않도록 화면 어딘가에 **"교육용 체험 도구"** 표시를 항상 둡니다.
